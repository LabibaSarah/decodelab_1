# This is the Decode Lab's first full stack web development project
# TaskFlow Dashboard

A responsive productivity dashboard built using HTML, CSS, and JavaScript.

## Features

- Responsive Design
- Dark Mode
- Task Manager
- Local Storage
- Task Search
- Due Dates
- Task Counter
- Mobile Navigation
- Contact Form

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- index.html
- style.css
- script.js

## How To Run

1. Download the project
2. Open `index.html`
3. Run in browser
